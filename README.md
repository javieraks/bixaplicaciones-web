# Bix Aplicaciones - Sitio Web

Landing page estática (HTML/CSS/JS) de Bix Aplicaciones, empresa de desarrollo de software a medida.

## Secciones incluidas
- Hero con llamado a la acción
- Estadísticas de la empresa
- Carrusel de logos de clientes (placeholder, reemplazar por logos reales)
- Servicios (9 servicios detallados)
- Cómo trabajamos (proceso en 5 pasos)
- Casos de éxito / proyectos (con problema, solución y resultado)
- Testimonios de clientes
- Sobre nosotros + valores
- Preguntas frecuentes (acordeón)
- Contacto (formulario + datos)
- Botón "volver arriba"

## Cómo verla

### Opción 1: GitHub Pages (online)
Activar en Settings > Pages > Source: rama `main`, carpeta `/ (root)`.
Queda disponible en: `https://javieraks.github.io/bixaplicaciones-web/`

### Opción 2: En tu computadora
1. Descargá el repositorio (botón "Code" > "Download ZIP").
2. Descomprimí el ZIP.
3. Abrí el archivo `index.html` con doble clic (se abre en el navegador).

## Estructura
- `index.html` — contenido y estructura de la página
- `style.css` — estilos y diseño responsive
- `script.js` — interactividad (menú móvil, carrusel, FAQ, formulario, botón subir)
