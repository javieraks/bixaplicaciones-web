# Bix Aplicaciones - Sitio Web

Landing page estática (HTML/CSS/JS) de Bix Aplicaciones, empresa de desarrollo de software a medida.

## Cómo verla

### Opción 1: GitHub Pages (online)
Una vez activado GitHub Pages en este repositorio, la página estará disponible en:
`https://javieraks.github.io/bixaplicaciones-web/`

### Opción 2: En tu computadora
1. Descargá el repositorio (botón "Code" > "Download ZIP").
2. Descomprimí el ZIP.
3. Abrí el archivo `index.html` con doble clic (se abre en el navegador).

## Estructura
- `index.html` — contenido y estructura de la página
- `style.css` — estilos y diseño responsive
- `script.js` — interactividad (menú móvil, formulario)
